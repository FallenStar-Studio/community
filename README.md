# Plyra Community / Plyra 社区

**English · 简体中文**

Welcome to the public discussion space for Plyra. Use GitHub Discussions to ask questions, share ideas, follow development, and give feedback. The repository also publishes a read-only JSON feed for the independent Plyra Community App.

欢迎来到 Plyra 的公开交流空间。你可以通过 GitHub Discussions 提问、分享想法、关注开发进展并反馈建议。本仓库也会为独立运行的 Plyra Community App 发布只读 JSON Feed。

## Project status / 项目状态

**Available now:** an independently runnable Godot 4 community-client prototype with bilingual UI, bundled demo discussions and MOD cards, and a local macOS build. The client contains adapters for the public community feed and MOD registry. Live feed reads begin after this repository's feed workflow is enabled and verified. GitHub sign-in and app-originated posting or commenting are not implemented or tested.

**当前已有：** 可独立运行的 Godot 4 社区客户端原型，包含双语界面、本地演示讨论与 MOD 卡片，以及 macOS 本地构建。客户端已包含公开社区 Feed 和 MOD 注册表适配器。此仓库的 Feed workflow 启用并验证后，客户端才开始读取线上 Feed。GitHub 登录以及客户端内发帖、评论尚未实现或测试。

**Planned:** Android, Windows and Linux validation; user authorization; safe discussion writes; and a reviewed MOD metadata directory. Plyra Compositor, Plyra World, and a released MOD ecosystem are future work, not released products.

**后续规划：** Android、Windows、Linux 验收；用户授权；安全的讨论写入；以及经审核的 MOD 元数据目录。Plyra Compositor、Plyra World 和正式发布的 MOD 生态仍属未来规划，并非已发布产品。
