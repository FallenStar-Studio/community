# Security reporting / 安全问题反馈

**English · 简体中文**

Please do not report an exploitable vulnerability in a public Discussion or issue. Use GitHub's **Report a vulnerability** feature on this repository to send a private report to the maintainers. Include affected versions, impact, and reproduction details when safe to do so. Do not include real credentials or another person's private data.

If the private reporting option is unavailable, contact an organization owner through GitHub and request a private security-reporting channel. Do not publish exploit details while arranging contact. The project does not promise a response time or a security-support SLA.

This project currently has no production service or released client with server-side account storage. The client prototype must never contain administrator credentials, personal access tokens, or OAuth client secrets.

请不要在公开 Discussion 或 Issue 中报告可被利用的安全漏洞。请使用本仓库的 GitHub **Report a vulnerability（报告漏洞）**功能，私下向维护者提交报告。请在安全的前提下说明受影响版本、影响范围和复现细节；不要附带真实凭据或他人的私人数据。

如果无法使用私密报告功能，请通过 GitHub 私下联系组织所有者并索取安全反馈渠道。联系期间不要公开漏洞利用细节。项目不承诺响应时限或安全支持服务等级。

本项目目前没有生产服务，也没有保存账号数据的已发布客户端。客户端原型不得包含管理员凭据、个人访问令牌或 OAuth Client Secret。
