# Discussion categories / 讨论分类

| Category | Format | Purpose / 用途 |
|---|---|---|
| Announcements | Announcement | Maintainer news, project status and community notices. / 维护者发布动态、项目状态和社区通知。 |
| General | Open discussion | General Plyra questions and conversations. / Plyra 相关的一般问题与交流。 |
| Ideas & Feedback | Open discussion | Product ideas, interface feedback and proposals. / 产品想法、界面反馈与提议。 |
| Development | Open discussion | Client implementation, architecture and development notes. / 客户端实现、架构和开发记录。 |
| Help & Support | Question and answer | Questions, troubleshooting and community help. / 问题、故障排查与社区互助。 |

These categories are for this repository's Discussions only. They do not claim that the planned Plyra Compositor, Plyra World, or MOD ecosystem has shipped.

以上分类仅用于本仓库的 Discussions，不表示规划中的 Plyra Compositor、Plyra World 或 MOD 生态已经发布。
