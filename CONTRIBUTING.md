# Contributing / 参与贡献

**English · 简体中文**

## Discussions

Choose a category that fits your topic. Include steps, platform and version details for help requests. Search for an existing conversation before opening a duplicate. Be clear about whether a feature is available, under development, or only proposed.

## Client code

The independent client source lives in [community-app](https://github.com/FallenStar-Studio/community-app). Open code issues and pull requests there. Keep GitHub access behind service interfaces, preserve offline demo behavior, and never add a personal access token, administrator token, or client secret.

## MOD metadata

The directory is a reviewed metadata index, not an installer or binary host. Propose an entry with a pull request to [mod-registry](https://github.com/FallenStar-Studio/mod-registry). Include a real HTTPS source and release URL, a verified SHA-256 digest, license, author, version, supported target, and compatibility statement. Maintainers may reject unsafe, incomplete, misleading, or unlicensed submissions.

## Language

English and Simplified Chinese are both welcome. A bilingual summary is appreciated when practical, but lack of a translation is not a reason to reject an otherwise useful contribution.

## 参与方式

### Discussions

选择合适的分类。求助时请提供复现步骤、平台和版本信息。发布前先搜索是否已有相同话题。请明确区分已可用功能、开发中功能和提议中的功能。

### 客户端代码

独立客户端源码位于 [community-app](https://github.com/FallenStar-Studio/community-app)。代码问题和 Pull Request 请提交到该仓库。GitHub 访问应留在服务接口之后，保留离线演示能力，且不得添加个人访问令牌、管理员令牌或 Client Secret。

### MOD 元数据

目录是经过审核的元数据索引，不是安装器或二进制托管平台。请向 [mod-registry](https://github.com/FallenStar-Studio/mod-registry) 提交 Pull Request。条目须包含真实 HTTPS 源码与发布地址、已核对的 SHA-256 摘要、许可证、作者、版本、适用目标和兼容性说明。维护者可以拒绝不安全、不完整、误导性或缺少授权的条目。

### 语言

欢迎使用英语或简体中文。条件允许时可附双语摘要，但不会仅因缺少翻译而拒绝有价值的贡献。
