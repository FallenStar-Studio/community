# Start here: what is available today / 从这里开始：当前可用内容

This is a quick guide to the project's current status:

- **Available now:** a standalone Godot 4 client prototype, English/Simplified Chinese UI, offline demo discussions and MOD cards, and a local macOS build.
- **Being connected:** this repository's GitHub Discussions and a static guest feed. You can already participate here in GitHub's web interface.
- **Not available yet:** GitHub account sign-in inside the client, creating posts or comments in the client, Android/Windows/Linux builds, and MOD installation.
- **Future projects:** Plyra Compositor and Plyra World are not released. The MOD directory is not a released ecosystem.

Use **General** for open conversation, **Ideas & Feedback** for proposals, **Development** for implementation, and **Help & Support** for questions. Check the [Roadmap](https://github.com/FallenStar-Studio/community/blob/main/ROADMAP.md) and [Contributing guide](https://github.com/FallenStar-Studio/community/blob/main/CONTRIBUTING.md) before posting.

---

以下是项目当前状态速览：

- **当前已有：** 可独立运行的 Godot 4 客户端原型、英语/简体中文界面、离线演示讨论与 MOD 卡片，以及 macOS 本地构建。
- **正在接入：** 本仓库的 GitHub Discussions 和静态游客 Feed。你现在可以直接通过 GitHub 网页参与交流。
- **尚不可用：** 客户端内 GitHub 账号登录、客户端内发帖或评论、Android/Windows/Linux 构建，以及 MOD 安装。
- **未来项目：** Plyra Compositor 和 Plyra World 尚未发布；MOD 目录也不等同于已发布生态。

请在 **General** 进行日常交流，在 **Ideas & Feedback** 提交提议，在 **Development** 讨论实现，在 **Help & Support** 提问。发帖前请查看[路线图](https://github.com/FallenStar-Studio/community/blob/main/ROADMAP.md)和[参与贡献指南](https://github.com/FallenStar-Studio/community/blob/main/CONTRIBUTING.md)。
