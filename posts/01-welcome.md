# Welcome to Plyra Community / 欢迎来到 Plyra 社区

Welcome! This repository is the public discussion space for Plyra. We are starting with a small, independent Godot Community client prototype and a bilingual community. Please introduce yourself, share what you are exploring, or ask a question in the category that fits best.

The current client can browse bundled demo discussions and MOD cards. GitHub sign-in, creating discussions and comments from the client, and Android/Windows/Linux builds are not available yet. The client remains independent of Plyra Compositor, Plyra World, and Steam.

Plyra Compositor, Plyra World, and a released MOD ecosystem are future work; they are not released products. The MOD directory is metadata-only and this client does not install or execute MODs.

Please read [Community rules](https://github.com/FallenStar-Studio/community/blob/main/CODE_OF_CONDUCT.md), [Contributing](https://github.com/FallenStar-Studio/community/blob/main/CONTRIBUTING.md), and [Roadmap](https://github.com/FallenStar-Studio/community/blob/main/ROADMAP.md). English and 简体中文 are both welcome.

欢迎来到 Plyra 社区！本仓库是 Plyra 的公开交流空间。我们从一个独立运行的 Godot 社区客户端原型和双语社区开始。欢迎自我介绍、分享正在探索的内容，或在合适的分类中提问。

当前客户端可以浏览本地演示讨论和 MOD 卡片。客户端内 GitHub 登录、创建讨论与评论，以及 Android/Windows/Linux 构建均尚不可用。客户端可独立运行，不依赖 Plyra Compositor、Plyra World 或 Steam。

Plyra Compositor、Plyra World 和正式发布的 MOD 生态仍属于未来规划，并非已发布产品。MOD 目录目前仅收录元数据，客户端不会安装或执行 MOD。

请阅读[社区规则](https://github.com/FallenStar-Studio/community/blob/main/CODE_OF_CONDUCT.md)、[参与贡献](https://github.com/FallenStar-Studio/community/blob/main/CONTRIBUTING.md)和[路线图](https://github.com/FallenStar-Studio/community/blob/main/ROADMAP.md)。欢迎使用英语或简体中文交流。
